# slitherrrrr_pink.io
 Slitherrrrr is a fun and minimal Snake-inspired game developed in C#, featuring a soft pink aesthetic and playful visuals. The goal is simple: control the snake on a grid-based board, collect “sass” to grow longer, and increase your score while keeping the snake alive.

This project focuses on implementing core game mechanics such as grid movement, collision detection, score tracking, and dynamic growth, all wrapped in a lighthearted and cute UI. The game was built as a learning project to explore C# game logic, event handling, and basic rendering concepts, while also experimenting with visual design.

Slitherrrrr is beginner-friendly, easy to play, and made purely for fun — a small but sassy take on the classic Snake game 🐍🎀

🎮 How to Play:
> Use the arrow keys to move the snake around the grid
> Eat the sass to grow longer and increase your score
> Avoid colliding with the walls or the snake’s own body
> The game ends when the snake crashes — try again and beat your high score!
